# Contact Page

A responsive contact page built while I was learning front-end development in 2023.

At the time, I was experimenting with JavaScript libraries, animations, and responsive layouts before starting my agency.


## Features
- Responsive layout
- Contact form
- GSAP animations
- Custom cursor
- Form validation

## Technologies
- HTML5
- CSS3
- JavaScript
- GSAP

## What I Learned
- Building responsive layouts with Flexbox
- Creating custom form validation
- Using GSAP for animations
- Organizing HTML, CSS, and JavaScript into separate files
